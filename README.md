1. Extract files.
2. Install Node.js here https://nodejs.org/
3. Make an account in Cesium and get a token here https://ion.cesium.com/tokens
4. Start the game clicking on Iniciar World Auto.bat file.
5. You can see the game in http://localhost:8000/World%20Auto.html
6. Enter the Cesium token (this is just once the first time you run the script).
7. Press W to move forward if the loading of 3d buildings gets too slow.
8. Press R to listen local radio.
9. Press P to open the Autopilot (you can just add the destination and the car will start from your current location).

This is just a software to test.
